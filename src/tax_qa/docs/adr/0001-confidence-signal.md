# Confidence is a similarity floor plus an LLM self-rating, not either alone

The agent must not improvise legal interpretation, so an Answer needs an honest signal when it isn't well-grounded. Pure LLM self-rating (mirroring the triage agent's `needs_escalation` pattern) risks the model sounding confident while citing a barely-relevant Clause. Pure retrieval-similarity thresholding can't distinguish "this Clause is on-topic but doesn't answer it" from "this Clause literally answers it." We combine them: a similarity threshold is a hard floor — if no retrieved Clause clears it, Confidence is forced to `not_found` regardless of what the LLM says — otherwise the LLM self-rates between `answered` and `uncertain`. This is a three-state signal, not binary, because "found something but unsure" and "document doesn't address this" call for different behavior (best-effort answer with a caveat vs. no synthesized answer at all).
